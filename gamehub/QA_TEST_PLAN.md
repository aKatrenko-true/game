> Подробный, актуальный план QA находится в [qa-project/README.md](qa-project/README.md). Этот файл оставлен для обратной совместимости со старой ссылкой.

## Текущий статус

- Каталог игроков и статистика отображаются после исправления JavaScript-селектора - результат подтверждён пользователем.
- Пользователь подтвердил, что новые записи сохраняются.
- Историческая ошибка Service Worker требует отдельного retest.
- Полный регрессионный прогон не завершён. Непроверенные сценарии остаются Не запускался.

## Диагностированный дефект frontend

До исправления интерфейс показывал «Игроки не найдены» и прочерки статистики. Console содержала ошибку `Uncaught TypeError: $(...).forEach is not a function`. Причина была в использовании одиночного селектора `$("[data-go]")` как коллекции. Селектор заменён на `$$("[data-go]")`; пользователь подтвердил, что игроки снова отображаются.

## Запуск автоматических API-тестов

Из папки `gamehub`:

```powershell
py -m pip install -r requirements.txt
pytest -q
```

**Важно:** этот тест-план не доказывает, что все сценарии выполнены. Для каждого запуска записывайте дату, ветку/commit, результат и фактические доказательства.
