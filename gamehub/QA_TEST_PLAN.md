# GameHub - мой тест-план

## 1. Что я тестирую
Я проверяю веб-приложение GameHub: каталог игроков, игровые профили, команды, матчи и REST API.

## 2. Что входит в мои проверки
- UI: отображение разделов, адаптивность, поиск и фильтры.
- API: HTTP-коды, формат ответа, валидация входных данных.
- Данные: создание профиля, уникальность никнейма, сохранение в SQLite.
- Регрессия: главная страница, каталог игроков, команды и матчи после добавления профиля.

## 3. Основные сценарии, которые я проверяю
| ID | Сценарий | Ожидаемый результат |
|---|---|---|
| TC-01 | Открыть главную страницу | Страница загружается, данные отображаются |
| TC-02 | Проверить GET /api/health | HTTP 200, status=ok |
| TC-03 | Получить список игроков | HTTP 200, массив игроков |
| TC-04 | Найти игрока по части никнейма | Возвращаются подходящие игроки |
| TC-05 | Отфильтровать игроков по игре | В ответе только выбранная игра |
| TC-06 | Создать профиль с корректными данными | HTTP 201, профиль сохранён |
| TC-07 | Создать второй профиль с тем же никнеймом | HTTP 409 |
| TC-08 | Указать никнейм короче 3 символов | HTTP 422 |
| TC-09 | Указать никнейм с пробелом или спецсимволом | HTTP 422 |
| TC-10 | Передать слишком длинный никнейм | HTTP 422 |
| TC-11 | Получить список команд | HTTP 200 |
| TC-12 | Создать матч, где команды одинаковы | HTTP 422 |
| TC-13 | Изменить статус матча на Live | HTTP 200, новый статус сохранён |
| TC-14 | Обновить несуществующий матч | HTTP 404 |
| TC-15 | Открыть сайт на узком экране | Основные элементы доступны без критичного наложения |

## 4. Нефункциональные проверки
- Удобочитаемые сообщения об ошибках.
- Работа основных сценариев на актуальном Chrome.
- Адаптивность для ширины экрана от 360 px.
- Проверка отсутствия ошибок в DevTools Console и Network.

## 5. Как я запускаю API-тесты
Из папки gamehub:

    python -m pip install -r requirements.txt
    pytest -q

## 6. Ограничения
Проект учебный. Регистрация профиля не включает пароль, аутентификацию или подтверждение email. Перед публичным запуском необходимо добавить защиту API, управление секретами и постоянное хранилище данных.
