# Краткий тест-план GameHub

Подробные сценарии - в [тест-кейсах](qa-project/TEST_CASES.md), результаты запусков - в [шаблоне отчёта](qa-project/TEST_RUN_TEMPLATE.md).

## Подтверждённые сведения

- Пользователь подтвердил, что после исправления JavaScript-селектора каталог игроков отображается.
- Пользователь сообщал, что новые записи сохраняются; отдельный свежий тест-отчёт не оформлен.
- В текущем `master` backend использует SQLite. Скриншоты PostgreSQL относятся к историческому деплою другой ветки.
- Историческая ошибка Service Worker требует повторной проверки.
- Полный регрессионный прогон не завершён.

## Автоматические тесты

В `gamehub/tests/test_api.py` есть тесты health, списка и создания игроков, дубликатов, валидации, поиска, создания матча против одной команды и LFG. Текущий результат неизвестен до запуска `pytest -q`.
