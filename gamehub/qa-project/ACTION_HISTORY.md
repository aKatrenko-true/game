## API и база данных

- Раньше `/api/players`, `/api/teams` и `/api/matches` возвращали `Not Found`.
- В историческом логе SQLite была ошибка `no such table: players`.
- Для опубликованного стенда подключили PostgreSQL и настроили переменные окружения. Секреты в документацию не копировали.
- После деплоя пользователь подтвердил, что API возвращает данные. Старый SQLite-сценарий отдельно не перепроверяли.

## Каталог игроков

- Игроки и статистика не отображались.
- В Console была ошибка `$(...).forEach is not a function`.
- В `gamehub/static/app.js` одиночный селектор заменили на `$$("[data-go]")`, который возвращает коллекцию элементов.
- После исправления пользователь подтвердил, что каталог отображается. На скриншоте видны 64 игрока, 6 команд, 5 матчей и результат поиска `abc`.
