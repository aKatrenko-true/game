# Баг-репорты GameHub

Здесь собраны ошибки, которые наблюдались раньше, и замечания по коду. Если дефект не проверен повторно, он остаётся открытым или историческим.

## GH-BUG-001 - Ошибка Service Worker

- **Статус:** нужна повторная проверка.
- **Где:** `gamehub/static/sw.js`.
- **Что наблюдалось:** в старом скриншоте Console была ошибка `Response body is already used`.
- **Ожидание:** Service Worker обрабатывает ответ без повторного чтения body.
- **Влияние:** возможны проблемы с кэшем; влияние не подтверждено.
- **Проверка:** не запускалась повторно.

## GH-BUG-002 - SQLite: отсутствует таблица players

- **Статус:** историческая проблема; исходный сценарий не перепроверен.
- **Где:** инициализация SQLite / `GET /api/players`.
- **Что было:** в логе появилась ошибка `no such table: players`, хотя health endpoint отвечал.
- **Ожидание:** таблицы созданы до обработки запросов, API возвращает массив игроков.
- **Сейчас:** позже пользователь подтвердил, что API работает на опубликованном PostgreSQL-стенде. Это не подтверждает исправление старого SQLite-сценария.

## GH-BUG-003 - API-маршруты возвращали Not Found

- **Статус:** историческая проблема; текущая работоспособность подтверждена пользователем.
- **Где:** `/api/players`, `/api/teams`, `/api/matches`.
- **Что было:** маршруты возвращали `404 Not Found`.
- **Ожидание:** каждый маршрут возвращает данные в согласованном формате.
- **Сейчас:** пользователь позже подтвердил, что API работает. Отдельного свежего отчёта с HTTP-ответами нет.

## GH-BUG-004 - Каталог игроков не отображался

- **Статус:** исправление подтверждено пользователем; полный ретест не оформлен.
- **Где:** `gamehub/static/app.js`.
- **Что было:** каталог и статистика не отображались. В Console была ошибка `$(...).forEach is not a function`.
- **Причина:** одиночный DOM-селектор использовался как коллекция.
- **Исправление:** селектор заменили на `$$("[data-go]")`.
- **Результат:** пользователь подтвердил, что каталог снова отображается. На доступном скриншоте видны 64 игрока, 6 команд, 5 матчей и результат поиска `abc`.
- **Осталось:** повторить сценарий на актуальной версии и проверить Console.

## GH-BUG-005 - Сохранение данных после обновления

- **Статус:** пользователь подтвердил сохранение; отдельный тест-отчёт не оформлен.
- **Где:** создание записи и база данных.
- **Что было:** требовалось убедиться, что новая запись не исчезает после обновления страницы.
- **Ожидание:** запись остаётся после обновления.
- **Результат:** пользователь сообщал, что запись сохраняется. Повторный тест с фиксацией запроса и ответа не оформлен.

## Как добавлять новый дефект

Записываю только то, что удалось увидеть или подтвердить:
1. Короткий заголовок.
2. Где возникла проблема.
3. Шаги воспроизведения.
4. Что произошло и что ожидалось.
5. Влияние и приоритет.
6. Скриншот, запрос или лог, если он есть.

Если ошибка пока только предполагается по коду, отмечаю её как риск, а не как воспроизведённый дефект.
