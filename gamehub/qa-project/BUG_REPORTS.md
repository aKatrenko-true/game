# Баг-репорты GameHub

Здесь собраны найденные ранее проблемы. Исторический дефект не считаю закрытым, пока не проверю его повторно. Скриншоты - в [реестре](screenshots/README.md).

## GH-BUG-001 - Ошибка Service Worker

- **Статус:** нужна повторная проверка.
- **Где:** PWA / `gamehub/static/sw.js`.
- **Приоритет:** предварительно P2; влияние не установлено.
- **Что было:** в Console наблюдалась ошибка `Failed to execute 'clone' on 'Response': Response body is already used`.
- **Ожидание:** Service Worker обрабатывает Response без повторного чтения body и необработанных исключений.
- **Доказательство:** историческое наблюдение; отдельного скриншота этой ошибки нет.
- **Retest:** не запускался.

## GH-BUG-002 - В SQLite отсутствовала таблица players

- **Статус:** историческая проблема; исходный сценарий не перепроверен.
- **Где:** инициализация SQLite / `GET /api/players`.
- **Приоритет:** P1.
- **Что было:** лог содержал `sqlite3.OperationalError: no such table: players`, хотя health endpoint отвечал.
- **Ожидание:** схема создаётся до обработки запросов, API возвращает массив игроков.
- **Сейчас:** пользователь позже подтвердил работу API на PostgreSQL-стенде. Это не подтверждает исправление исходного SQLite-сценария.

## GH-BUG-003 - API-маршруты возвращали Not Found

- **Статус:** историческая проблема; пользователь позже подтвердил работу API.
- **Где:** `/api/players`, `/api/teams`, `/api/matches`.
- **Приоритет:** P1.
- **Что было:** маршруты возвращали `Not Found`.
- **Ожидание:** маршруты доступны и возвращают JSON-массивы.
- **Причина:** не установлена.
- **Что изменилось:** Render переключали на `feature/postgres-persistence`.
- **Доказательство:** [скриншот деплоя](screenshots/README.md). Свежего отчёта с HTTP-кодами нет.

## GH-BUG-004 - Игроки не отображались при наличии данных в API

- **Статус:** пользователь подтвердил исправление; полная регрессия не выполнена.
- **Где:** frontend / `gamehub/static/app.js`.
- **Приоритет:** P1, Major.
- **Шаги:** открыть сайт, перейти в «Игроки», проверить каталог и Console.
- **До исправления:** «Игроки не найдены», прочерки в статистике и ошибка `Uncaught TypeError: $(...).forEach is not a function`.
- **Причина:** одиночный селектор `$("[data-go]")` использовался как коллекция.
- **Исправление:** его заменили на `$$("[data-go]")`.
- **Результат:** пользователь подтвердил, что игроки отображаются и новые записи сохраняются. На скриншоте видны 64 игрока, 6 команд, 5 матчей и результат поиска `abc` - `ABCPOG`.
- **Осталось:** отдельно проверить поиск, фильтры, навигацию, команды и матчи.

## GH-BUG-005 - Риск публикации секретов на скриншотах

- **Статус:** профилактическая проверка; утечка не подтверждена.
- **Где:** QA-доказательства / Render Environment.
- **Ожидание:** пароли, токены, cookies и значения секретных переменных не попадают в репозиторий.
- **Проверка перед публикацией:** убедиться, что значения на скриншоте замаскированы.
