# GameHub - план развития

Рабочий список задач. Приоритеты можно менять по результатам проверки и обратной связи.

## GH-FEAT-01. Поиск напарника и LFG - в работе

**Зачем:** игроку нужно быстро найти людей для конкретной игры, ранга и времени.

### Критерии приёмки
- Объявления можно просматривать без входа в аккаунт.
- По умолчанию отображаются только открытые объявления.
- Можно отфильтровать объявления по игре, региону и платформе.
- Авторизованный пользователь может создать объявление с форматом, рангом, регионом, платформой, языком, временем игры и описанием.
- Неавторизованный пользователь не может создать объявление.
- Некорректный формат и слишком длинные поля отклоняются сервером.
- Пользователь может закрыть только своё объявление.
- На мобильном экране форма и карточки не вызывают горизонтальный скролл.

**Что пока не сделано:** фильтры по рангу, языку и времени игры в интерфейсе; редактирование текста объявления; удаление объявления; срок жизни объявления; жалобы на объявление; защита от спама и лимиты частоты запросов.

## GH-FEAT-02. Состав команд и заявки

- Просмотр состава команды и капитана.
- Просмотр открытых команд по игре.
- Авторизованный игрок отправляет заявку на вступление.
- Капитан принимает или отклоняет заявку.
- Нельзя отправить повторную активную заявку в ту же команду.
- Участник не может сам назначить себя капитаном или изменить чужую заявку.

## GH-FEAT-03. Личный кабинет

- Редактирование никнейма по правилам уникальности.
- Аватар с проверкой типа и размера файла.
- Описание профиля с ограничением длины.
- Несколько игровых профилей/предпочтений, если модель данных будет расширена.
- Пользователь видит и закрывает собственные LFG-объявления.
- Выход из аккаунта и корректное поведение просроченной сессии.

## GH-FEAT-04. Жалобы и модерация

- Пользователь отправляет жалобу на объявление или профиль с категорией и комментарием.
- Повторная отправка одинаковой жалобы ограничена.
- Модератор видит очередь жалоб и меняет статус.
- Решение модерации сохраняется в журнале.
- Пользователь не может вызывать административные API без прав.
- Не возвращать хеши паролей, токены или внутренние секреты в API-ответах.

## GH-FEAT-05. PWA и устройства

- Manifest содержит название, цвета и иконки подходящих размеров.
- Проверить установку на Android/Chrome и добавление на экран «Домой» на iOS/Safari.
- Проверить обновление service worker без ручного удаления данных браузера.
- Проверить offline fallback и обозначить, какие функции без сети недоступны.
- Проверить safe-area, экран запуска, ориентацию и основные размеры экранов.
- Не обещать полностью офлайн-работающее приложение, если API требует сеть.

## Текущие ограничения
Это учебный проект. Перед использованием реальными людьми нужны дополнительная проверка безопасности, защита от злоупотреблений, ограничение запросов, политика хранения данных и надёжное постоянное хранилище.
