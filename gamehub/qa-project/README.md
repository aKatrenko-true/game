## Статусы

- **Pass** - проверка прошла.
- **Fail** - проверка не прошла.
- **Blocked** - проверку не удалось выполнить.
- **Не запускался** - проверку ещё не выполняли.
- **Подтверждено пользователем** - результат сообщён пользователем, отдельного прогона QA нет.

## Локальный запуск

Из папки `gamehub`:

```bash
python -m pip install -r requirements.txt
pytest -q
```

Команда запуска не подтверждает, что тесты прошли: результат нужно получить после выполнения.
