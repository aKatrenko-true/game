- **Общий статус QA:** In progress. Пользователь подтвердил работу каталога и сохранение новых записей; полный прогон всего набора не подтверждён.

## Статусы тестирования

- **Pass** — тест фактически выполнен, результат совпал с ожидаемым.
- **Fail** — тест выполнен, результат отличается от ожидаемого.
- **Blocked** — выполнить нельзя из-за среды или зависимости.
- **Not Run** — не запускался.
- **Confirmed by user** — результат сообщён пользователем, но не является независимым запуском QA.
- **Historical / Retest required** — проблема наблюдалась ранее, актуальный статус не установлен.

Не отмечать тест пройденным только на основании успешного деплоя или health-check. Ссылки на скриншоты вести в [реестр доказательств](screenshots/README.md); не называть отсутствующий файл приложенным доказательством.

## Порядок работы

1. Зафиксировать ветку, commit, окружение и изменение.
2. Сверить требования, код, API-контракт и существующие тесты.
3. Выполнить smoke-проверки и ключевые API.
4. При проблеме UI проверить Console и Network.
5. Записать баг-репорт с шагами, фактическим и ожидаемым результатом, приоритетом и доказательствами.
6. После исправления выполнить retest и регрессию затронутых областей.
7. Сохранить доказательства и указать фактический статус.
8. Обновить тестовую документацию так, чтобы она отражала актуальное состояние продукта.

## Локальные тесты API

Из каталога `gamehub`:

```bash
python -m pip install -r requirements.txt
pytest -q
```

Локальный Swagger UI: `http://127.0.0.1:8000/docs`.

Команда описывает способ запуска, но сама по себе не подтверждает успешный результат. Фактический отчёт следует сохранить после запуска тестов.

## Риски и безопасность

- По ранее сохранённым сведениям, бесплатная PostgreSQL-база Render требовала решения о продлении/переносе до 12 ноября 2026 г.; актуальный статус нужно проверить перед тестовым прогоном.
- Бесплатный web service может засыпать.
- Service Worker может отдавать устаревшие ресурсы.
- Не публиковать пароли, токены, cookies, личные данные и открытые значения секретов Render.
- Полный прогон admin/LFG, responsive, accessibility, security и Service Worker пока не подтверждён.
