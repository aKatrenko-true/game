# GameHub QA Project

Отдельный QA-проект для проверки GameHub — учебного сервиса поиска игровых напарников и команд. Документация ведётся отдельно от разработки приложения, как в продуктовой команде.

## Продукт
- **Приложение:** GameHub
- **Тестовый стенд:** https://gamehub-055p.onrender.com
- **Репозиторий:** https://github.com/aKatrenko-true/game/tree/master/gamehub
- **Тип тестирования:** web, REST API, функциональное, регрессионное, адаптивность, PWA, базовые проверки безопасности.
- **Статус тестирования:** In progress. Тест-кейсы описаны; выполнение и результаты фиксируются отдельно. Не отмечать тест пройденным без фактической проверки.

## Как работаем
1. Уточняем требования и критерии приёмки.
2. Выбираем тест-кейсы по риску и области изменений.
3. Проверяем сценарии на стенде или локально.
4. При дефекте создаём баг-репорт с шагами, фактическим и ожидаемым результатом, окружением и доказательствами.
5. После исправления выполняем retest и затронутую регрессию.
6. Фиксируем фактический результат и ограничения релиза.

## Тестирование API локально
Из папки `gamehub`:

```bash
python -m pip install -r requirements.txt
pytest -q
```

Swagger UI: `http://127.0.0.1:8000/docs`

## Важные правила портфолио
- Отделять подтверждённые результаты от планируемых проверок.
- Не публиковать пароли, токены, cookies, личные данные или секреты Render.
- Не использовать реальные персональные данные в тестах.
- При демонстрации проекта честно обозначать, какие проверки ручные, какие автоматизированы, а какие ещё не запускались.
