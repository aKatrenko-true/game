# Чек-лист регрессии GameHub

Отмечай пункт после фактической проверки. Незапущенные сценарии оставляй пустыми.

## A. Smoke и API
- [ ] Главная открывается: `GH-SM-001-home.png`.
- [ ] `/api/health` возвращает успешный ответ: `GH-SM-002-health.png`.
- [ ] `/api/players`, `/api/teams`, `/api/matches` возвращают JSON без 404/500: `GH-API-001-players.png`, `GH-API-002-teams.png`, `GH-API-003-matches.png`.

## B. Каталог игроков
- [ ] Счётчики и популярные записи отображаются.
- [ ] В Console нет ошибки `$(...).forEach is not a function`.
- [ ] Поиск и фильтр игры работают вместе и отдельно.
- [ ] Карточки игр и навигация ведут в нужный раздел.
- [ ] Сверить [скриншот до и после исправления](screenshots/README.md).

## C. Создание и сохранение
- [ ] Создать уникальный тестовый профиль.
- [ ] Профиль появляется в каталоге.
- [ ] После обновления страницы запись остаётся.
- [ ] Сохранение после перезапуска проверено отдельно, если перезапуск допустим.
- [ ] Не создавать дубликаты без необходимости.

## D. Команды и матчи
- [ ] Команды и матчи загружаются.
- [ ] Доступные фильтры и статусы работают по текущему интерфейсу.
- [ ] Ошибка одного endpoint не оставляет страницу в бесконечной загрузке.

## E. Render / PostgreSQL
- [ ] Render Live, branch и commit соответствуют проверяемой версии.
- [ ] PostgreSQL доступен.
- [ ] DATABASE_URL настроен; значение не копируется в отчёт.
- [ ] SEED_DEMO_DATA проверен без публикации секретов.
- [ ] Данные сохраняются после обновления.

## F. PWA
- [ ] После hard reload нет ошибки `Response body is already used`.
- [ ] Service Worker регистрируется без необработанных ошибок.
- [ ] После деплоя загружается новая версия frontend.
- [ ] Offline-поведение соответствует заявленным возможностям.

## G. Адаптивность и клавиатура
- [ ] Проверены 360, 390, 768, 1024 и 1440 px.
- [ ] Нет критического горизонтального переполнения.
- [ ] Фокус виден, основные действия доступны с клавиатуры.

## H. Админка и LFG
- [ ] Права администратора проверяются на сервере.
- [ ] Обычный пользователь не может выполнить admin-действие.
- [ ] LFG проверен по актуальному OpenAPI.
- [ ] Незапущенные проверки не отмечены как пройденные.
