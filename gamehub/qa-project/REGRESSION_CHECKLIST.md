# GameHub — чек-лист регрессии

Ставить отметку только после фактической проверки.

## Главная и навигация
- [ ] Главная загружается без критичных ошибок.
- [ ] Счётчики игроков, команд и матчей соответствуют API.
- [ ] Навигация desktop переключает разделы.
- [ ] Нижнее меню mobile переключает разделы.
- [ ] Кнопка создания профиля открывает форму.
- [ ] Закрытие формы работает кнопкой и предусмотренным поведением диалога.
- [ ] Карточки игр ведут в каталог с выбранным фильтром.

## Игроки
- [ ] Каталог загружается.
- [ ] Поиск работает для полного и частичного никнейма.
- [ ] Фильтр игры работает и сбрасывается.
- [ ] Пустой результат отображается корректно.
- [ ] Валидный профиль создаётся и появляется в каталоге.
- [ ] Дубликат и невалидный никнейм обрабатываются понятной ошибкой.

## Команды и матчи
- [ ] Каталог команд загружается.
- [ ] Матчи отображаются с правильными статусами.
- [ ] Фильтры матчей работают.
- [ ] Создание/обновление матча проверено по API.
- [ ] Ошибки API не приводят к зависанию UI.

## PWA / качество
- [ ] В консоли нет новых необработанных ошибок.
- [ ] В Network нет неожиданных 4xx/5xx.
- [ ] Service Worker обновляет ресурсы после деплоя.
- [ ] Нет горизонтального скролла на 360 и 390 px.
- [ ] Контент не перекрывается нижней навигацией.
- [ ] Фокус клавиатуры виден.
- [ ] Сайт проверен после очистки/обновления кэша и в обычном режиме.

## Административная часть — перед публичным использованием
- [ ] Неавторизованный запрос не может выполнить административное действие.
- [ ] Пользователь без admin-роли не может получить admin-права через прямой API-запрос.
- [ ] Удаление/блокировка требуют подтверждения и корректно обрабатывают ошибки.
- [ ] Смена пароля инвалидирует старые сессии согласно требованиям.
- [ ] Пароли, cookies и токены не попадают в логи/ответы.


## Регрессия после исправления отображения игроков и подключения PostgreSQL

- [ ] `GET /api/players` возвращает непустой массив, когда в БД есть игроки.
- [ ] Каталог отображает данные из API, а не «Игроки не найдены».
- [ ] Счётчики игроков, команд и матчей соответствуют количеству данных API.
- [ ] Поиск по никнейму и фильтр игры работают вместе и по отдельности.
- [ ] Карточки игр и навигация открывают правильный раздел.
- [ ] Создание нового профиля завершается успешно; профиль появляется в списке.
- [ ] После обновления страницы новый профиль остаётся в каталоге.
- [ ] После перезапуска сервиса данные сохраняются (проверять только если перезапуск допустим).
- [ ] `/api/health`, `/api/players`, `/api/teams`, `/api/matches` не возвращают неожиданные 404/500.
- [ ] Console не содержит `$(...).forEach is not a function`.
- [ ] Service Worker не сообщает об ошибке `Response body is already used`.
- [ ] После hard reload загружается исправленный frontend, а не устаревшая версия из кэша.
