# GameHub — чек-лист регрессии

Ставить отметку только после фактической проверки.

## A. Smoke и API
- [ ] Главная открывается: `GH-SM-001-home.png`.
- [ ] `/api/health` возвращает успешный ответ: `GH-SM-002-health.png`.
- [ ] `/api/players`, `/api/teams`, `/api/matches` возвращают ожидаемый JSON без 404/500: `GH-API-001-players.png`, `GH-API-002-teams.png`, `GH-API-003-matches.png`.

## B. Исправление отображения игроков
- [ ] Счётчики игроков, команд и матчей отображаются.
- [ ] Популярные игроки и каталог заполнены данными API.
- [ ] В Console нет `$(...).forEach is not a function`.
- [ ] Поиск и фильтр игры работают вместе и по отдельности.
- [ ] Карточки игр и навигация ведут в правильный раздел.
- [ ] Исходная ошибка: [скриншот Console](screenshots/README.md); после исправления: [скриншот UI](screenshots/README.md).

## C. Создание и сохранение
- [ ] Создать один уникальный тестовый профиль.
- [ ] Профиль появляется в каталоге.
- [ ] После обновления страницы запись остаётся.
- [ ] Сохранение после перезапуска проверено отдельно, если перезапуск допустим.
- [ ] Не создавать дубликаты тестовых записей без необходимости.

## D. Команды и матчи
- [ ] Команды загружаются и отображаются.
- [ ] Матчи загружаются и отображаются.
- [ ] Доступные фильтры/статусы работают согласно текущему UI.
- [ ] Ошибка одного endpoint не оставляет интерфейс в бесконечной загрузке.

## E. Render / PostgreSQL
- [ ] Render Live и branch/commit соответствует проверяемой версии.
- [ ] PostgreSQL Available.
- [ ] DATABASE_URL настроен в окружении сервиса; значение не копируется в отчёт.
- [ ] SEED_DEMO_DATA проверен без публикации секретов.
- [ ] Данные сохраняются после обновления страницы.

## F. PWA
- [ ] После hard reload нет ошибки `Response body is already used`.
- [ ] Service Worker регистрируется без необработанных ошибок.
- [ ] После деплоя загружается новый frontend.
- [ ] Offline-поведение соответствует заявленным возможностям.

## G. Responsive / клавиатура
- [ ] Проверены 360, 390, 768, 1024 и 1440 px.
- [ ] Нет критического горизонтального переполнения.
- [ ] Клавиатурный фокус виден и действия доступны.

## H. Admin / LFG
- [ ] Права admin проверены на сервере.
- [ ] Обычный пользователь не может выполнить admin-действие.
- [ ] LFG проверен по актуальному OpenAPI.
- [ ] Непроверенные функции остаются Not Run.
