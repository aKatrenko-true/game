## 8. Администрирование

Админ-панель открывается по `/admin`, но сама страница не является проверкой авторизации. Защита реализована на API: запросы к `/api/admin/*` должны содержать заголовок `X-Admin-Password`; если `ADMIN_PASSWORD` не настроен, API возвращает HTTP 503, при неверном или отсутствующем пароле — HTTP 401. В реализации нет проверки «обычной пользовательской роли» для этих запросов: используется общий пароль администратора.

| ID | Приоритет | Предусловия | Шаги | Ожидаемый результат | Доказательство |
|---|---|---|---|---|---|
| GH-ADM-001 | P0 | Известно состояние переменной `ADMIN_PASSWORD` | Вызвать `GET /api/admin/summary` без заголовка `X-Admin-Password` | При настроенном пароле API возвращает HTTP 401; если пароль не настроен — HTTP 503 | не приложено |
| GH-ADM-002 | P0 | `ADMIN_PASSWORD` настроен | Вызвать `GET /api/admin/summary` с неверным паролем, затем с правильным | Неверный пароль даёт HTTP 401, правильный позволяет получить сводку; не публиковать сам пароль | не приложено |
| GH-LFG-001 | P1 | API доступен | Выполнить `GET /api/lfg`, затем запросы с фильтрами `game`, `region` и `platform` | HTTP 200; выдача соответствует переданным фильтрам | не приложено |
| GH-LFG-002 | P1 | Пользователь не вошёл в аккаунт | Отправить `POST /api/lfg` без авторизации | API возвращает HTTP 401 | не приложено |

## Автоматические API-тесты в репозитории

В `gamehub/tests/test_api.py` есть проверки health, списка игроков, создания игрока и дубликата, валидации никнейма, поиска, запрета матча команды против самой себя и нескольких сценариев LFG. Их наличие в коде не означает, что они прошли в последнем запуске. Для текущего результата нужен запуск тестов или успешный CI на конкретном commit.
