## 5. База данных и деплой

В `master` файл `gamehub/app.py` использует SQLite. Скриншоты PostgreSQL/Render относятся к историческому развёртыванию; актуальную конфигурацию стенда нужно проверить отдельно.

| ID | Приоритет | Предусловия | Шаги | Ожидаемый результат | Доказательство |
|---|---|---|---|---|---|
| GH-DB-001 | P1 | Открыт Render | Проверить Live, branch и commit | Зафиксирована версия, которая реально развёрнута | [исторический скриншот Render](screenshots/README.md) |
| GH-DB-002 | P1 | Известно используемое окружение | Определить фактическую СУБД по коду и конфигурации стенда | Документация не смешивает SQLite и PostgreSQL | [исторический скриншот PostgreSQL](screenshots/README.md) |
| GH-DB-003 | P1 | Открыта конфигурация окружения | Проверить необходимые переменные, не копируя значения секретов | Настройки соответствуют выбранному окружению | [исторический скриншот Environment](screenshots/README.md) |
| GH-DB-004 | P1 | Тестовый профиль создан | Обновить страницу и сверить данные с доступным источником истины | Запись сохраняется в фактически используемой базе | не приложено |

## 7. LFG и администрирование

В коде есть API для LFG и тесты на авторизацию. Проверки интерфейса и прав администратора нужно сверять с актуальной реализацией; не считать их выполненными по наличию кейса.

| ID | Приоритет | Предусловия | Шаги | Ожидаемый результат | Доказательство |
|---|---|---|---|---|---|
| GH-ADM-001 | P0 | Нет admin-сессии | Проверить доступ к админке и защищённому API | Сервер запрещает неавторизованное действие, если маршрут защищён | не приложено |
| GH-ADM-002 | P0 | Обычная сессия | Попробовать admin-операцию | Сервер проверяет роль и запрещает действие | не приложено |
| GH-LFG-001 | P1 | Стенд доступен | Проверить GET `/api/lfg` и фильтры по OpenAPI | Ответ соответствует фактическому контракту | не приложено |
| GH-LFG-002 | P1 | Нет авторизации | Отправить POST `/api/lfg` без сессии | В текущих API-тестах ожидается HTTP 401 | не приложено |

## Автоматические API-тесты

Файл `gamehub/tests/test_api.py` содержит тесты health, списка и создания игроков, дубликата, валидации, поиска, матча против той же команды и LFG. Эти тесты существуют в репозитории, но их текущий результат нужно получить запуском `pytest -q`.
