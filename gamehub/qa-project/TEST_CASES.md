## 5. База данных и деплой

В `master` файл `gamehub/app.py` использует SQLite. Скриншоты PostgreSQL/Render относятся к историческому развёртыванию; актуальную конфигурацию стенда нужно проверить отдельно.

| ID | Приоритет | Предусловия | Шаги | Ожидаемый результат | Доказательство |
|---|---|---|---|---|---|
| GH-DB-001 | P1 | Открыт Render | Проверить Live, branch и commit | Зафиксирована версия, которая реально развёрнута | `GH-DB-018-postgres-deploy.png` |
| GH-DB-002 | P1 | Известно используемое окружение | Определить фактическую СУБД по коду и конфигурации стенда | Документация не смешивает SQLite и PostgreSQL | `GH-DB-015-postgres-connect.png` |
| GH-DB-003 | P1 | Открыта конфигурация окружения | Проверить необходимые переменные, не копируя значения секретов | Настройки соответствуют выбранному окружению | `GH-DB-017-environment.png` |
| GH-DB-004 | P1 | Тестовый профиль создан | Обновить страницу и сверить данные с доступным источником истины | Запись сохраняется в фактически используемой базе | `GH-PL-002-persistence-refresh.png` |

## Автоматические API-тесты

Файл `gamehub/tests/test_api.py` содержит тесты health, списка и создания игроков, дубликата, валидации, поиска, матча против той же команды и LFG. Эти тесты существуют в репозитории, но их текущий результат нужно получить запуском `pytest -q`.
