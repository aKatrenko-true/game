Статусы:
- **Pass** — фактический результат совпал с ожидаемым.
- **Fail** — фактический результат отличается от ожидаемого; создать или обновить баг-репорт.
- **Blocked** — проверку не удалось выполнить из-за блокирующего условия.
- **Не запускался** — проверку не выполняли.
- **Подтверждено пользователем** — результат сообщил пользователь, независимого прогона нет.
