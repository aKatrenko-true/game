## Выполнение
| Test ID | Статус | Что получилось | Bug ID / доказательство |
|---|---|---|---|
| GH-SM-001 | Not Run | — | — |
| GH-SM-002 | Not Run | — | — |

Статусы:
- **Pass** — проверено, результат совпал с ожидаемым.
- **Fail** — проверено, результат не совпал с ожидаемым; создать баг-репорт.
- **Blocked** — проверить не удалось из-за окружения или зависимости.
- **Not Run** — ещё не запускалось.
