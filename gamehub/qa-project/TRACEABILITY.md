# Связь тестов и дефектов

| Область сайта | Тест-кейсы | Дефекты | Что известно |
|---|---|---|---|
| Главная и доступность | GH-SM-001, GH-SM-002 | - | Отдельный прогон не оформлен |
| API игроков, команд и матчей | GH-API-001…003 | GH-BUG-002, GH-BUG-003 | Пользователь подтвердил, что API работает; свежие HTTP-ответы не сохранены |
| Каталог и статистика | GH-FE-001…003 | GH-BUG-004 | Исправление подтверждено пользователем; скриншот после исправления есть |
| Поиск и фильтры | GH-FE-004…006 | - | Поиск `abc` виден на скриншоте; остальные сценарии не запускались |
| Создание и сохранение профиля | GH-PL-001…004 | GH-BUG-005 | Пользователь сообщил о сохранении; отдельный отчёт не оформлен |
| PostgreSQL и деплой | GH-DB-001…004 | GH-BUG-002, GH-BUG-003 | Есть скриншоты Render; актуальное состояние нужно сверить перед новым прогоном |
| Service Worker | GH-PWA-001…002 | GH-BUG-001 | Историческая ошибка, повторная проверка не выполнена |
| Команды и матчи | GH-TE-001, GH-MA-001…002 | - | Полный функциональный прогон не выполнен |
| Адаптивность и клавиатура | GH-RWD-001, GH-A11Y-001 | - | Не запускались |
| Админка и LFG | GH-ADM-001…002, GH-LFG-001…002 | - | Нужна отдельная проверка |

## Как обновлять таблицу

Добавь тест-кейс, выполни его, запиши результат. Если проверка не прошла - создай баг-репорт и свяжи ID. После исправления повтори тест и проверь связанные функции.
