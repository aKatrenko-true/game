# Матрица трассировки требований и тестов

Матрица отражает план покрытия. Наличие тест-кейса не означает его выполнение.

| Область | Тест-кейсы | Дефекты | Состояние доказательств |
|---|---|---|---|
| Доступность приложения | GH-SM-001, GH-SM-002 | - | Отдельный test run не оформлен |
| API players/teams/matches | GH-API-001…003 | GH-BUG-002, GH-BUG-003 | Пользователь подтвердил текущую работоспособность; отдельные HTTP-отчёты не сохранены |
| Каталог и статистика | GH-FE-001…003 | GH-BUG-004 | Исправление подтверждено пользователем; скриншот after-fix доступен |
| Поиск и фильтры | GH-FE-004…006 | - | Поиск `abc` виден на скриншоте; полный набор Не запускался |
| Создание/сохранение профиля | GH-PL-001…005, GH-DB-004 | - | Пользователь подтвердил сохранение; подробный test run не оформлен |
| PostgreSQL/деплой | GH-DB-001…004 | GH-BUG-002, GH-BUG-003 | Есть скриншоты Render; учитывать срок бесплатной базы |
| Service Worker/cache | GH-PWA-001…003 | GH-BUG-001 | Historical issue; retest Не запускался |
| Команды/матчи | GH-TE-001, GH-MA-001…002 | - | Данные видны на скриншоте; полный функциональный прогон Не запускался |
| Responsive/keyboard | GH-RWD-001, GH-A11Y-001 | - | Не запускался |
| Admin | GH-ADM-001…002 | - | Требует отдельной проверки |
| LFG | GH-LFG-001…002 | - | Требует сверки текущего API и отдельного прогона |

## Правило обновления
1. Зафиксировать требование и ожидаемый результат.
2. Добавить тест-кейс.
3. Выполнить проверку и записать фактический статус.
4. При Fail создать баг-репорт и связать ID теста.
5. После исправления выполнить retest и затронутую регрессию.
