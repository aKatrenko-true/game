# Матрица тестов и дефектов

Матрица показывает связь между областями сайта, тест-кейсами и известными проблемами. Наличие кейса не означает, что его запускали.

| Область | Тест-кейсы | Дефекты | Статус доказательств |
|---|---|---|---|
| Главная и доступность | GH-SM-001, GH-SM-002 | - | Отдельный прогон не оформлен |
| API игроков, команд и матчей | GH-API-001…003 | GH-BUG-002, GH-BUG-003 | Пользователь сообщал о работе API; свежие HTTP-ответы не сохранены |
| Каталог и статистика | GH-FE-001…003 | GH-BUG-004 | Исправление подтверждено пользователем; скриншот после исправления есть |
| Поиск и фильтры | GH-FE-004…006 | - | На скриншоте виден поиск `abc`; остальные сценарии не запускались |
| Создание и сохранение профиля | GH-PL-001…005, GH-DB-004 | - | Пользователь сообщил о сохранении; независимый прогон не оформлен |
| Состояние базы и деплой | GH-DB-001…004 | GH-BUG-002, GH-BUG-003 | Есть исторические скриншоты Render; актуальную версию нужно сверить |
| Service Worker и cache | GH-PWA-001…003 | GH-BUG-001 | Историческая ошибка; повторная проверка не выполнена |
| Команды и матчи | GH-TE-001, GH-MA-001…002 | - | Полный функциональный прогон не оформлен |
| Адаптивность и клавиатура | GH-RWD-001, GH-A11Y-001 | - | Не запускались |
| Администрирование | GH-ADM-001…002 | - | Требуется проверка маршрутов и прав по текущему коду |
| LFG | GH-LFG-001…002 | - | В API есть LFG-маршруты и тесты; отдельный прогон не выполнен |

## Как обновлять матрицу

1. Связать кейс с подтверждённым требованием или функцией из кода.
2. Выполнить проверку и записать результат.
3. При Fail создать баг-репорт и связать ID.
4. После исправления выполнить retest и связанную регрессию.
