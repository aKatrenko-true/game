# Матрица тестов и дефектов

Матрица показывает, что покрыто кейсами и какие результаты уже подтверждены. Само наличие кейса не означает, что его запускали.

| Область сайта | Тест-кейсы | Дефекты | Что известно |
|---|---|---|---|
| Главная и доступность | GH-SM-001, GH-SM-002 | - | Отдельный прогон не оформлен |
| API игроков, команд и матчей | GH-API-001…003 | GH-BUG-002, GH-BUG-003 | Пользователь подтвердил работу API; свежие HTTP-ответы не сохранены |
| Каталог и статистика | GH-FE-001…003 | GH-BUG-004 | Исправление подтверждено пользователем; скриншот после исправления есть |
| Поиск и фильтры | GH-FE-004…006 | - | Поиск `abc` виден на скриншоте; остальные кейсы не запускались |
| Создание и сохранение профиля | GH-PL-001…005, GH-DB-004 | - | Пользователь подтвердил сохранение; отдельный test run не оформлен |
| PostgreSQL и деплой | GH-DB-001…004 | GH-BUG-002, GH-BUG-003 | Есть скриншоты Render; перед новым прогоном нужно сверить стенд |
| Service Worker и cache | GH-PWA-001…003 | GH-BUG-001 | Историческая ошибка; повторная проверка не выполнена |
| Команды и матчи | GH-TE-001, GH-MA-001…002 | - | Полный функциональный прогон не оформлен |
| Адаптивность и клавиатура | GH-RWD-001, GH-A11Y-001 | - | Не запускались |
| Администрирование | GH-ADM-001…002 | - | Требуется отдельная проверка |
| LFG | GH-LFG-001…002 | - | Нужно сверить API и выполнить отдельный прогон |

## Как обновлять матрицу

1. Добавить кейс под требование.
2. Выполнить проверку и записать результат.
3. При Fail создать баг-репорт и связать ID.
4. После исправления повторить кейс и затронутую регрессию.
