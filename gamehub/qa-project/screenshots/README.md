# GameHub QA — скриншоты

В этой папке хранятся изображения-доказательства для баг-репортов и тест-кейсов.

## Соглашение об именах

- `GH-BUG-006-after-fix.png` — интерфейс после исправления отображения игроков.
- `GH-FE-001-network-before-fix.png` — Network до исправления.
- `GH-FE-002-console-error.png` — ошибка JavaScript до исправления.
- `GH-DB-015-postgres-connect.png` — состояние PostgreSQL.
- `GH-DB-017-environment.png` — настройки окружения Render; секреты должны быть скрыты.
- `GH-DB-018-render-deploy.png` — статус деплоя Render.

После загрузки изображений добавляйте относительные ссылки на них в соответствующие записи `../BUG_REPORTS.md` и тест-кейсы в `../TEST_CASES.md`.

Скриншоты являются доказательствами наблюдений. Не размещайте здесь пароли, токены, cookies или другие секретные данные.
